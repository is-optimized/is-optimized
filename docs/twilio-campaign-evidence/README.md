# Prelaunch SMS opt-in evidence

These screenshots show the planned report-delivery flow rendered from the released Go HTML template with SMS display enabled. They are prelaunch evidence for Twilio campaign review, not a claim that SMS delivery is currently active on is-optimized.com. The live service keeps SMS disabled until A2P approval and secure provider configuration are complete.

The screenshots use synthetic values (`example.com`, `Alex`, and a nonfunctional report code). They contain no customer information. The live website remains available without SMS; the screenshot shows the optional phone and consent step before a user sends a prefilled report request.
