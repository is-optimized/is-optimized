# Report-delivery opt-in — prelaunch evidence

Generated 2026-11-06 from the Go server template in this branch with the report-only disclosure. Synthetic example.com and reserved example phone number. SMS remains disabled on production; these screenshots show the flow intended for enablement after campaign approval. No SMS was sent. The handoff uses a synthetic zero correlation code and cannot deliver a report.

The visitor enters the number they will send from, sees the one-message report-delivery disclosure and legal links, and chooses Text me the report. Opening the composer is not consent or delivery: the visitor must send the prepared report request. The service validates the inbound sender and expiring report code, then sends one PDF report link. Skip text and view HTML report requires neither phone nor SMS consent. Marketing and calling permission are absent; legacy marketing flags are ignored.

These screenshots supersede the October 30 campaign screenshots. Historical evidence is retained for audit only.
